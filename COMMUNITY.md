### How to Contribute

1. **Report Bugs**
   - Use the feedback button in the dashboard
   - Or create an issue on GitHub
   - Include steps to reproduce

2. **Request Features**
   - Use the feedback button in the dashboard
   - Or create a feature request on GitHub
   - Explain the use case

   - Write blog posts about your experience
