## 🎮 Usage

### Run Individual Systems

```bash
cd tools/automation-systems

# Customer support
npm run customer-support process '{"id":"123","subject":"Help"}'

# Content generator
npm run content-generator generate "AI automation"

# SEO
npm run seo audit https://example.com

# Lead generation
npm run lead-generation identify '{"industry":"tech"}'

# A/B testing
npm run ab-testing create '{"name":"Test"}'

# Feature development
npm run feature-development analyze '{"title":"New feature"}'
```

### Run Full Automation Cycle

```bash
npm run run-all
```

This runs all 6 systems with AI intelligence and safety checks.
