## 🎮 Usage

### Run Complete Workflow

```bash
cd tools/revenue-analytics

# Run complete revenue analytics workflow
npm run run
```

**Workflow:**
1. Get revenue data (MRR, ARR, trends)
2. Get customer data (LTV, churn, cohorts)
3. Get unit economics (CAC, LTV:CAC, payback)
4. Get operational metrics (costs, profit, burn)
5. Get automation ROI (ROI, time saved, revenue)
6. Generate AI forecasts (revenue, customers)
7. Generate recommendations (prioritized actions)
8. Generate unified dashboard (real-time)

### Run Individual Systems

```bash
# Revenue tracking
npm run revenue-tracker

# Customer analytics
npm run customer-analytics

# Unit economics
npm run unit-economics

# Operational tracking
npm run operational-tracker

# Automation ROI
npm run automation-roi

# AI forecasting
npm run ai-forecasting

# Recommendations
npm run recommendations

# Dashboard
npm run dashboard
```

### Orchestrator Commands

```bash
# Run complete workflow
node orchestrator.js run

# Get unified summary
node orchestrator.js summary

# Generate real-time dashboard
node orchestrator.js dashboard
```
