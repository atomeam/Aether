## Pattern Structure

### Knowledge Item Schema

Every addition follows the same structure:

```typescript
{
  id: string;           // Unique identifier
  title: string;        // Human-readable name
  type: string;         // Category (mobile, emulation, skills, ai, retro, game-engine)
  source: string;       // Where it came from
  extractedAt: string;  // When it was added
  insights: string[];   // Key learnings
  related: string[];    // Connections to other items
  tags: string[];       // Searchable keywords
}
```

### Integration Process

**Step 1: Extract**
- Analyze the source (APK, ZIP, GitHub, Internet Archive)
- Extract value (insights, patterns, techniques)
- Document findings

**Step 2: Structure**
- Convert to knowledge item schema
- Add metadata (source, date, type)
- Tag appropriately

**Step 3: Integrate**
- Add to backend knowledge array
- Update frontend OneHub component
- Commit and push

**Step 4: Verify**
- Test API response
- Test frontend display
- Verify data flows correctly

**Step 5: Deploy**
- Push to GitHub
- Deploy to Vercel
- Verify deployment
