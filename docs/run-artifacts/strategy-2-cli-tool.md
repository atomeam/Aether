## Features
- Multi-platform deployment: Vercel, Netlify, Cloudflare Pages, Railway, Render
- System monitoring: Health checks and metrics
- Interactive setup: Configuration wizard
- Pro access integration: Direct payment via CLI

## Usage
```bash
# Install
npm install -g @aether/cli

# Deploy
aether deploy --platform vercel --token YOUR_TOKEN --id YOUR_PROJECT

# Monitor
aether monitor

# Setup wizard
aether setup

# Get Pro Access
aether pro
aether pro --email your@email.com
```
